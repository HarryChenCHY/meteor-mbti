## 一、产品简介

**星陨人格宇宙**（Meteor MBTI Universe）是一款将 **MBTI 人格测试** × **星座 / 血型 / 个人偏好** × **天文知识闯关** 三类要素融合的浪漫向 Web 互动产品。

用户在站内填写一组人格 / 形象偏好参数，系统将"铸造"出一颗专属于自己的虚拟陨石（拥有名称、宇宙编号、技能、轨迹、性格描述与每日宇宙播报）；随后用户通过参与 6 大主题、3 个难度的天文知识答题积累"星星能量"，驱动陨石从胚芽形态逐阶演化至超新星形态，并解锁主题专属皮肤与积分商城奖励。

### 一句话定位

> "把你的性格、星座、记忆与宇宙信息，铸造成唯一的陨石生命体。"

### 关键体验链路

```
铸造陨石 → 观看诞生 → 答题积能 → 解锁皮肤 → 形态进化 → 积分兑换 → 永久档案
```

## 二、产品目的与目标

### 2.1 业务目的

| 维度 | 目的 |
| --- | --- |
| **用户价值** | 提供一段兼具仪式感与知识性的"造物 + 养成"体验，让用户产生独特的情感锚点 |
| **教育价值** | 借助 270 道天文知识题，把抽象的天文学常识转化为低门槛的趣味闯关 |
| **运营价值** | 通过形态演化、皮肤解锁、积分商城构建可持续的回访动机；为线下天文馆 / 周边商品提供数字化引流入口 |
| **品牌价值** | 以"陨石人格"作为差异化 IP 概念，形成有辨识度的 UGC 与社交分享载体 |

### 2.2 用户目标（Job-to-be-Done）

- "我希望有一个能代表我独特个性的虚拟形象（不是千篇一律的头像）。"
- "我想边玩边学一点天文知识，但讨厌枯燥的题库 App。"
- "我希望我的累积有可视化的成长反馈和稀有度区分。"

### 2.3 成功度量（建议指标）

- **D1 / D7 留存率**：≥ 35% / ≥ 18%
- **平均答题轮次 / 用户**：≥ 3 轮
- **皮肤解锁率**：≥ 25% 用户至少解锁 1 款主题皮肤
- **积分商城点击转化**：≥ 12%

## 五、功能模块详细需求

### 5.1 首页（`/`）

#### 功能描述
品牌门户，承担一次性传达世界观与引导首次使用的职责。

#### 模块构成
1. **Hero 区**
   - 居中陨石球（`MeteorOrb` 三维 / 着色器渲染，level=4 超新星形态展示）
   - 大标题"星陨人格宇宙" + 副标题英文 + slogan
   - 主 CTA：「🌠 立即生成我的陨石」→ `/create`
   - 次 CTA：「积分商城」→ `/shop`
   - 背景层：`LiquidEther` 流体雾霭（紫粉渐变） + 9 颗 `PlanetSphere` 行星视差漂浮（鼠标移动产生 parallax 偏移）+ 3 道光线条纹 + 顶部紫色光带分隔线
2. **已诞生的星陨**
   - 4 张示例卡片（不同 MBTI / 星座 / 等级），展示陨石外观差异
3. **铸造逻辑**
   - 视觉化公式：`MBTI + 星座 + 血型 + 年龄 + 照片 + AI 推演 = 专属陨石人格`
4. **成长系统**
   - 三卡片导流：天文答题 / 陨石养成 / 积分兑换
5. **永生机制**
   - 文案区强调"永久宇宙编号 + 星际档案馆"
6. **Footer**

#### 交互细节
- 鼠标在 hero 区移动时，行星按各自 `parallax` 系数（0.018–0.032）反向偏移，制造空间纵深
- 仅在支持 hover 的设备启用视差（移动端禁用）
- 卡片入场带 `fade-in` 错峰动画（每张延迟 0.08s）

### 5.2 创建陨石（`/create`）

#### 功能描述
4 步分步表单，收集生成陨石所需的全部参数。

#### 步骤定义

| 步骤 | 标题 | 字段 | 控件类型 |
| --- | --- | --- | --- |
| **STEP 1/4** | 基础人格信息 | 昵称、MBTI（16 选 1）、星座（12 选 1）、血型（4 选 1）、年龄 | input + select |
| **STEP 2/4** | 上传形象信息 | 头像照片（必选）、风格参考图（可选）、生成风格（4 选 1：偏可爱 / 偏神秘 / 偏酷感 / 偏治愈） | 上传框 + tag 选择 |
| **STEP 3/4** | 生成偏好选择 | 角色形态（更像陨石 / 更像宇宙精灵）、视觉风格（3D 手办感 / 卡通插画感）、人格倾向（守护型 / 探索型 / 预言型 / 社交型） | 卡片单选 |
| **STEP 4/4** | 确认铸造 | 信息回显（9 项），CTA 按钮「🌠 开始铸造我的陨石人格」 | 只读卡片 + 按钮 |

#### 交互细节
- 顶部进度条 4 段 hairline，已完成段为白色 70% 透明度，未完成段为 8%
- 步骤切换带 `page-enter` 进入动画（key=step 触发重渲染）
- 「下一步」「上一步」轻量文本按钮，第 4 步收起「下一步」
- 未必填字段允许跳过（确认页用 mock 默认值兜底）

#### 数据校验（建议）
- MBTI、星座、血型为下一步必填
- 年龄为 8–99 范围数字
- 头像建议 ≤ 5 MB，JPG/PNG

### 5.5 天文知识闯关（`/quiz`）⭐ 核心模块

#### 功能描述
积分主要获取通道；以"主题—难度—一轮 12 题"为单位的闯关循环。

#### 5.5.1 题库设计

- **总量**：270 题
- **结构**：6 主题 × 3 难度 × 15 题
- **主题列表**：

| ID | 名称 | 图标 | 解锁皮肤 | 皮肤色 |
| --- | --- | --- | --- | --- |
| solar-system | 太阳系 | ☀️ | 烈焰陨石 | #ff6b35 |
| stellar-evolution | 恒星演化 | ⭐ | 星核陨石 | #ffd700 |
| galaxy-universe | 星系与宇宙 | 🌌 | 深空陨石 | #4a9eff |
| space-exploration | 航天探索史 | 🚀 | 先驱陨石 | #a8ff78 |
| astronomical-observation | 天文观测 | 🔭 | 晶眸陨石 | #e0c3fc |
| astrophysics | 宇宙物理 | ⚛️ | 量子陨石 | #ff9a9e |

- **难度档**：初级（easy） / 中级（medium） / 高级（hard），每档 15 题
- **题目结构**：

```js
{ id, topic, difficulty, q: '题干', opts: ['A','B','C','D'], ans: 0~3, explanation: '解析' }
```

#### 5.5.2 视图状态机

页面用单组件 + state 切换 4 个视图：

```
topic（主题选择） → difficulty（难度选择） → session（答题中） → result（本轮结果）
```

#### 5.5.3 主题选择视图

- 6 张主题卡（3 列网格）
- 卡内显示：图标、主题名、通关进度（0/3）、3 段难度进度条 hairline
- 已解锁皮肤：右上角显示彩色 chip（如「✨ 烈焰陨石」）
- 点击进入难度选择视图

#### 5.5.4 难度选择视图

- 3 张难度卡纵向堆叠
- 状态规则：
  - **初级**：默认解锁
  - **中级**：通关初级后解锁
  - **高级**：通关中级后解锁
- 卡片 UI：
  - 通关：显示「✓ 已通关」chip + 「再挑战」按钮
  - 解锁未通关：显示「开始」按钮 + 历史最佳分数（如 "8/12"）
  - 锁定：opacity 50%，按钮禁用，提示"通关初级解锁"

#### 5.5.5 答题中视图

- 顶部：`{topic} · {difficulty}` eyebrow + 「第 N / 12 题」+ 右侧实时答对数 + 连击提示（连续 ≥ 2 时显示「🔥 连续 N」）
- 题目卡：
  - MeteorOrb 小图 + 「答对 +20⚡ · 连击三题额外 +10⚡」提示
  - 题干 + 4 个选项卡片
- 答题反馈：
  - 选中后立即标色（正确：白色高亮；错误：暗灰；正确答案高亮 +0.45 透明度白边）
  - 解析展示在分隔线下方
  - 1.6s 后自动进入下一题
- 底部：12 个圆点进度指示 + 「放弃本轮，返回主题选择」弱链接
- 答对即时奖励：
  - **基础**：+20⚡ 即刻入账
  - **连击奖励**：每连续答对第 3 / 6 / 9 / 12 题，额外 +10⚡

#### 5.5.6 本轮结果视图

- 大型陨石球（level = 答对题数 / 3，最高 level 4）+ 通关 / 未通关文案
- 数据：答对 N / 12 + 通关阈值 9 + 最长连击数
- 奖励卡（仅通关时显示）：
  - 通关 +50⚡
  - 首次解锁主题皮肤 +100⚡（合计最高 +150⚡）
- 解锁皮肤大卡（首次通关高级时）：主题色边框 + 皮肤名称
- CTA：再挑战一次 / 换难度 / 返回主题

#### 5.5.7 答题进度持久化

- 存储位置：`localStorage` key=`meteor_quiz_progress`
- 存储字段：

```js
{
  topics: {
    'solar-system': { easy: 'unlocked'|'passed', medium: 'locked'|'unlocked'|'passed', hard: ... },
    ...
  },
  unlockedSkins: ['flame', 'stellar', ...],
  stats: {
    totalAnswered: 0,
    totalCorrect: 0,
    topicBest: { 'solar-system-easy': 11, ... }
  }
}
```

- 进度更新规则（`recordSession`）：
  - 累计答题数与正确数
  - 更新该主题 + 难度的历史最高分
  - 通关后推进下一难度状态
  - 高级通关首次解锁皮肤

## 六、核心数据模型

### 6.1 能量系统

| 维度 | 规则 |
| --- | --- |
| 初始值 | 62（首次进入） |
| 唯一获取途径 | 答题（每对 +20，连击 3 题再 +10，通关 +50，新皮肤 +100） |
| 消耗途径 | 商城兑换（spendEnergy） |
| 持久化 | 当前为内存态（`useState`），后续可迁移至 `localStorage` 或后端 |

### 6.2 阶段阈值（`STAGE_THRESHOLDS`）

```js
[0, 100, 300, 600, 1000]
```

`getStage(energy)` 自下向上找到第一个达到阈值的阶段；`getStageProgress(energy)` 计算当前阶段的百分比进度。

### 6.3 答题进度（`meteor_quiz_progress`）

见 5.5.7。

### 7.2 技术栈

## 八、视觉设计规范

### 8.1 设计基调

- **风格**：太空 / 极简 / 高级感；大量留白 + 细描边 + 微辉光
- **氛围**：神秘、浪漫、克制；避免饱和重色块

### 8.2 颜色

| 用途 | 色值 |
| --- | --- |
| 页面背景 | `#060606` |
| 主文字 | `rgba(255,255,255,0.85)` |
| 次文字 | `rgba(255,255,255,0.45)` |
| 弱提示 | `rgba(255,255,255,0.25)` |
| 主辉光 | 紫色系 `#8b5cf6` / `#a78bfa` / `#c4b5fd` |
| 强调 / CTA | 白色按钮 + 紫色描边发光 |

### 8.3 排版

- 字体：系统默认 sans（中文优先 PingFang / 微软雅黑）
- 标题：tracking-tight，font-weight 600–700
- 段落：行高 1.6–1.7，颜色 white/45–55
- eyebrow：uppercase + tracking-wide

### 8.4 组件规范

- 圆角统一：卡片 12px / 16px，按钮 8px，胶囊 9999
- 描边：`border-white/08 ~ /15`
- 卡片背景：`rgba(255,255,255,0.02 ~ 0.04)` + 背景模糊
- 阴影：极少使用 box-shadow，靠辉光 + 描边层次
